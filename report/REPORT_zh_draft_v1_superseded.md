## 摘要

我在美国凯斯西储大学(CWRU)轴承数据中心的公开数据上,做了一套完整的滚动轴承故障诊断流程,从时域波形一直做到一条可辩护的判定规则,并与一个有监督分类器作对照。核心结果如下:直接频谱无法定位故障频率;包络谱可以,外圈与内圈记录在各自的理论故障频率上分别取得 **635** 与 **237** 的峰背比,而健康记录在同一流程下的最高值为 **9.7**,实测频率误差分别为 **+0.4%** 与 **-0.25%**。共振带的选择不靠目测,而由一个对故障类型盲的谐波梳评分在 55 个候选频带上搜索决定,判定阈值由健康记录在完全相同的搜索下的最高分 **11.06** 标定。九条故障记录中,六条内外圈记录全部诊断正确,**出现一次假阳性**(滚动体 0.021 in,判为内圈)。滚动体故障在三种坑径下均未被正确诊断。分类器在按文件分组时达到 **96.3%**,但当留出的故障坑径是未见过的时,时域特征退化到 **33.1%**,而三分类的随机基线是 **33.3%**——不是效果微弱,是没有信息。

## 2. 数据(约 400 字 + 表)

### 2.1 来源与构成

**表 1 — 本研究使用的记录**

| 项 | 值 |
|---|---|
| 使用记录数 | 40 |
| 构成 | 健康 + 3 种故障位置 × 3 种坑径,每种 4 个电机负载 |
| 采样率 | 故障记录 12 kHz;基线记录 48 kHz,4 倍抽取 |

### 2.2 故障特征频率

倍数取自 CWRU 公布的 6205-2RS JEM 轴承规格,乘以轴频 n = rpm / 60。

**表 2 — 故障频率倍数**

| | 倍数 | 1772 rpm 下(n = 29.53 Hz) |
|---|---|---|
| BPFO,外圈 | 3.5848 | 105.9 Hz |
| BPFI,内圈 | 5.4152 | 159.9 Hz |
| BSF,滚动体 | 4.7135 | 139.2 Hz |
| FTF,保持架 | 0.39828 | 11.8 Hz |

全文只需要读者跟随一次算术。以 1 hp 负载、转速 1772 rpm 为例,轴频 n = 1772 / 60 = 29.53 Hz,外圈故障特征频率

> BPFO = 3.5848 × 29.53 Hz = 105.9 Hz

其余两个频率同理。这个数值在任何测量之前就已确定,它是后文全部判据的立足点。

### 2.3 数据中发现的三处缺陷

我把 `src/verify_data.py` 从原先硬编码的四个文件扩展到整个记录清单之后,发现了三处问题。三者现均已写成断言。

**(a) 基线记录的采样率是 48 kHz,而文档没有说明这一点。** 数据源的设备说明页只笼统给出 12 kHz,并注明 48 kHz "用于驱动端轴承故障",对基线记录只字未提。我改由数据本身确定:在已知为 12 kHz 的故障记录中存在 145.7 / 159.5 / 189.1 Hz 三根机器谱线;把基线记录按 48 kHz 读取时,这三根线落在同样的频率上,而按 12 kHz 读取时落在四分之一处。时长也一致:按 48 kHz 读出 10.08 s,与故障记录的约 10.2 s 相符,而按 12 kHz 读则为 40.3 s。如果按 12 kHz 读取基线,整条频率轴会整体错四倍,并且**不会报任何错**。

**(b) file 99 中包含 file 98 通道的逐字节副本。** 该文件同时含有 `X099_DE_time` 和 `X098_DE_time`,后者与 file 98 的数据到最后一个采样点都完全相同。按字母序取第一个键,就会把 file 98 的样本当成 file 99 的返回——同一份数据以两个标签出现在数据集中两次,这会跨越任何训练/测试划分造成泄漏。我修改了加载器,使其优先选取携带该文件自身编号的变量。

**(c) file 97 只有 5.08 s,而其余记录均为约 10 s。** 采样率不是问题所在:该记录中的六根机器谱线只有在按 48 kHz 读取时才落到已知 12 kHz 记录对应的位置上,按 24 kHz 或 12 kHz 读都相差甚远。它只是一段较短的录音。我把它记为一个已知例外,而不是放宽时长检查。

另外,四条基线记录中有两条携带 `RPM` 变量、两条没有;四条均不含故障记录所带的底板通道。

> 我把这三处放在数据一节而不是局限一节,理由是:发现它们本身是工作的一部分,而且它们是"这份数据被检查过而不是被直接消费"的证据。

## 3. 方法(约 900 字)

### 3.1 故障频率为什么在那里

滚动体每经过滚道上的一个缺陷,就产生一次冲击。缺陷位置固定时,冲击以一个由轴承几何和转速共同决定的速率重复。因此**故障的身份携带在冲击重复的频率上**,而这个频率在测量之前已由第 2.2 节的乘法给出:BPFO = 3.5848 × n。

诊断的任务,就是把这个重复率从信号中测出来。

### 3.2 直接频谱为什么找不到它

一次持续不足一毫秒的冲击在频域上是宽带的。它的能量并不落在"它多久重复一次"这个频率上,而是落在它所激起的结构共振上。

这一点在能量分布上是显性的。1 hp、0.007 in 记录中,外圈记录 **97.4%** 的谱能量位于 2000–4000 Hz,而位于 500 Hz 以下的只有 **0.2%**——恰恰是理论预测故障频率所在的那个频段。相对于健康记录,外圈记录在 3000–4000 Hz 携带 **1382 倍**的能量、在 2000–3000 Hz 携带 **379 倍**的能量,但在 0–500 Hz 只有 **0.5 倍**,比健康记录还少。

所以直接对原始信号做傅里叶变换,是在一个能量几乎不存在的频段里找一根峰。

### 3.3 包络分析

解决办法是分两步:先把信号限制到共振所在的频带,再测这个频带内能量起伏的节奏。

具体流程是:四阶巴特沃斯带通、零相位滤波;取希尔伯特包络;去均值;做傅里叶变换。

希尔伯特变换的作用是由实信号构造解析信号,其模即为瞬时幅值,也就是包络。带通必须放在取包络之前:包络反映的是整个输入信号的幅值起伏,若不先把其他成分滤除,得到的就是全部机械活动的混合起伏,而不是共振被冲击调制的那一部分。

去均值这一步不能省。包络是一个模,恒为正,不去均值会在 0 Hz 处留下一根峰。我实测该直流峰为 BPFO 峰的 **2.3 倍**——这不是通常描述的那种灾难性后果,但足以在自动缩放的纵轴上把所有真实峰压到一半,并使任何自动寻峰失效。

我在一个合成信号上验证了这条链路。该信号按每 1/105.9 s 一次的冲击激励一个 3 kHz 的衰减共振,并埋在三倍于它的噪声之下——这正是上述物理模型,因此答案由构造已知。直接 FFT 在 105.9 Hz 处的峰背比为 **3.0**;包络谱为 **31.8**,峰位于 **105.90 Hz**。

### 3.4 共振带的选择

这一小节承担本报告的主要分量。

**循环论证的陷阱。** 我在前一节使用的频带是目测确定的。要把它换成有依据的选择,自然的想法是"哪个频带在故障频率处的峰背比最高就选哪个"。但这个做法要求先知道去哪个频率量峰,而那恰恰是待诊断的对象。用答案挑参数,再用挑出的参数得出答案,是自证。

**区分已知与未知。** 诊断之前真正掌握的是:轴承型号(可拆检或查设备档案)、它的四个频率倍数(厂家几何参数)、转速(转速表直读),因此 BPFO / BPFI / BSF 三个候选频率的具体数值是已知的。未知的只有一件事——三者之中哪一个真的存在故障。

因此合法的做法是:对每一个候选频带,把三个候选频率**全部**评一遍分,取其中最高分作为该频带的得分,同时记下是哪一个候选胜出。选得分最高的频带,也就同时选定了它所支持的诊断。全过程不使用答案。

**评分:谐波梳。** 得分定义为候选频率 1× 至 4× 处峰背比的**几何平均**。采用几何平均而非算术平均,是因为几何平均要求每一根谐波都在:任何一根塌下去,整个乘积被拖低。算术平均则允许单独一根特别高的谱线把总分扛起来——而第 3.2 / 4.2 节已经表明,单独一根高峰完全可能是机器谱线。

**搜索网格。** 55 个候选频带,带宽 500 / 1000 / 2000 Hz,中心自 250 Hz 起每 250 Hz 一档,至 5800 Hz。

**为什么不用峭度。** 峭度是 kurtogram 的常用判据。在本数据上,两种判据所选频带能保住的"可达最佳峰背比"的比例为:

**表 3 — 两种选带判据的保留率**

| | 峭度 | 谐波梳 |
|---|---|---|
| 外圈 | 23.9% | **98.5%** |
| 内圈 | 64.4% | **95.8%** |
| 滚动体 | 26.9% | 33.8% |

峭度度量的是冲击性,而冲击可以来自传感器打火、单次机械磕碰和滤波器振铃,并不比来自轴承更少见。谐波梳评分额外要求周期性,这是单次事件伪造不出来的。

一个具体实例:在加入边缘裁剪之前,峭度判据为外圈记录选中的是 250–750 Hz;首尾各裁掉 5% 之后,选择变为 4750–5750 Hz。原先那个选择实际上是 `filtfilt` 自身的启动暂态——它不报错,而且看上去像一个结果。

**阈值。** 健康记录在**完全相同的 55 带搜索**下能达到的最高分为 **11.06**;其在单个频带上的中位数为 **3.57**,90 分位数为 **8.55**。若以单频带数值作为阈值,就忽略了"一组带噪声的数取最大值必然大于其中任何一个"这一事实,会制造出假阳性。阈值必须由同样经历过这一选择偏倚的流程标定。

### 3.5 分类

特征分两族,共 9 个。时域三个:RMS、峭度、峰值因子。包络六个:BPFO、BPFI、BSF 及其二倍频处的峰背比。

包络特征采用峰背比而非能量占比。在留出未见坑径的划分下,峰背比得 **50.7%**,能量占比得 **42.1%**。原因在分母:能量占比的分母是该段自身的总能量,而它主要编码的是负载和坑径,恰恰是分类器不应依赖的量;峰背比的分母是该频率邻域的背景,整体振动强度被约掉。

分段不重叠。若使用重叠窗口,相邻两段共享采样点,把其中一段置于训练集、另一段置于测试集即构成泄漏。

四种划分,各自提出不同的问题:A 随机打乱(几乎不提问);B 按文件分组(换一条新录音还认得吗);C 留一负载(换个工况还认得吗);D 留一故障坑径(换一个没见过的故障还认得吗)。越往后越接近现场条件。

## 5. 讨论与局限(约 700 字)

### 5.1 结果的含义

两种方法的**失败方式不同**,而这个差别就是本报告的结论。

第 3.4 节的规则是在测量一个由几何预测的量。它需要的输入是轴承型号、转速和三个由此算出的候选频率,这些在诊断之前就存在,与故障有多大无关。因此当坑径变成训练集里没有的尺寸时,它照样成立——它本来就不依赖"见过"。

分类器学习的是一个从波形到标签的映射。这个映射随坑径改变,因此一旦超出见过的形态就失效。需要强调的是,分类器并非没有物理输入:它的六个包络特征正是在三个理论故障频率及其二倍频处量出的峰背比,并且故障频率是按记录逐条计算的。物理信息确实起了作用——在划分 D 上,包络特征得 50.7% 而时域特征得 33.1%。但物理在这里只是一条**可选线索**,模型没有义务使用它,而在训练集上"认簇"比"比较三个峰背比"更省力也更准,于是它走了前者。

时域统计量在划分 D 上得到 33.1%,而基线是 33.3%,**这是全报告中最锋利的单个结果**——不是效果微弱,是没有效果。它与第 4.1 节的观察相互印证:这三个统计量在打乱样本顺序时不变,而故障类型只存在于顺序之中。

### 5.2 局限

以下每一条都是结论,不是致歉。每一条都指明了结果边界的一个具体位置。

1. **单一公开数据集、单一轴承型号、单一试验台。** 实验室数据远比工厂现场干净,本报告的全部数值都应在这个前提下理解。
2. **故障是由电火花加工切出的单点缺陷**,而不是真实轴承在服役中发展出的剥落。缺陷的几何形态不同,激起的冲击特性也不同。
3. **滚动体故障在三种坑径下均未被诊断出来。** 它的频带能量充足但不被调制——有检测,无诊断。这不是某一条记录的偶然,而是贯穿第 4.1 至 4.6 节的一致现象。
4. **九条记录中有一次假阳性**,且该阈值无法把它与唯一一条勉强正确的记录分开。三档规则处理了这个问题的表现,没有消除问题本身。
5. **分类器未在远离这四个负载的转速区间上测试过**,也未在另一台机器上测试过。第 4.6 节中划分 C 的结果表明跨负载泛化在本数据上并不困难,这不应被外推为跨机器泛化也不困难。
6. **谐波梳的谐波个数与频带网格是手工固定的**,只做了粗网格与细网格的对照检查,没有做系统的敏感性分析。
7. **全文使用的分段长度在两种划分上都不是最优**:1024 点的泛化更好(D 为 60.6%),4096 点的组内分数更高(B 为 94.2%)。

### 5.3 后续工作

三项具体的下一步。其一,把第 3.4 节的规则在第二个数据集上测试,以区分"方法成立"与"在这份数据上成立"。其二,针对滚动体故障采用循环平稳(cyclostationary)方法,因为本报告的证据表明该故障的能量存在但缺乏本方法所依赖的那种周期性调制。其三,把阈值改为逐机器标定,由该机器自身录制的健康基线在相同搜索流程下确定,而不是沿用本数据上的 11.06。

这个项目里最有价值的材料是我犯的错,因为每一个都附带一条可以带走的一般性结论。
